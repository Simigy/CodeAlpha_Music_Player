# CodeAlpha Music Player

A modern, responsive music player built with **vanilla HTML, CSS, and JavaScript**.

## 🚀 Live Demo

**[https://simigy.github.io/CodeAlpha_Music_Player/](https://simigy.github.io/CodeAlpha_Music_Player/)**

## ✨ Features

- **Play / Pause / Next / Previous** controls
- **Progress bar** with click-to-seek functionality
- **Volume control** with mute toggle
- **Playlist** with active track highlighting
- **Shuffle & Repeat** modes
- **Spinning album art** animation
- **Glassmorphism** dark UI
- Responsive design

## 🛠️ Tech Stack

- **HTML5** — semantic markup & `<audio>` API
- **CSS3** — Glassmorphism, Flexbox, CSS animations
- **JavaScript (ES6+)** — vanilla, no libraries
